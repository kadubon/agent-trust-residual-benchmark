# Agent Trust and Residual Benchmark v0.1.0

This is the initial public research release of the Agent Trust and Residual Benchmark (ATRB).
ATRB compares an unvalidated local-model judgment with five cumulatively layered compatibility
adapters for evidence, authority, provenance, residual obligations, independent verification, and
time-bound claims. It performs no real external action.

## Included in this release

- 18 synthetic negative-control fixtures with 20 expected failure labels.
- Six comparison conditions and a complete 108-decision matrix.
- Deterministic mock mode and an optional local Ollama mode.
- A sanitized full run using `qwen3.6:35b-a3b`, including raw outputs, normalized decisions,
  ledgers, residuals, metrics, runtime data, and SHA-256 publication manifests.
- Commands for publication sanitization, safety scanning, and integrity verification.
- Scientific documentation, a first-reader guide, citation metadata, and links to related projects.

## Bounded scientific result

In the included run, all 18 model responses were schema-valid. The raw-model condition rejected all
18 cases at its primary `accepted` field, but two cases contained inconsistent secondary permission
fields. The final cumulative compatibility-adapter condition detected 20/20 expected failure labels
and produced 0/18 false promotions in the supplied fixtures.

Intermediate false-promotion counts were not monotonic: 2/18 for raw output, 10/18 for PIC-only,
9/18 for PIC plus FOST, 5/18 after PFG, 2/18 after CCR, and 0/18 after temporal-claim checks. This
supports a fixture-conformance claim about implemented failure coverage; it does not show that every
added layer is universally better than the raw model.

## Essential limitations

All 18 cases are negative controls. The release therefore cannot estimate safe-artifact acceptance,
false-rejection rate, balanced accuracy, or general utility. Fixtures and validators were developed
together, conditions are cumulative, and the workcells are deterministic simulations. The result
does not establish real-world agent safety, truth, external-project equivalence, or statistical
generalization beyond the included fixtures.
