# Agent Trust and Residual Benchmark v0.2.0

ATRB v0.2.0 adds balanced controls, explicit near misses, repeated local-model calls, separate
rationale-coding tools, and an allowlisted publication workflow while preserving the v0.1 command
surface.

## Included in this release

- 36 synthetic fixtures: 18 positive controls and 18 negative controls.
- 15 near-miss cases: eight positive and seven negative.
- Five raw replications per case in the completed full-profile run.
- Balanced structured metrics for acceptance, rejection, reuse, action permission, field
  consistency, and near-miss decisions.
- Blinded rationale-coding export/import kept separate from the primary score.
- A sanitized Ollama result bundle with 16 hashed artifacts and a zero-blocking-finding safety scan.
- Complete protocol, first-reader explanation, scientific analysis, case logs, and regression tests.

## Bounded scientific result

The full run attempted 180 calls to `qwen3.6:35b-a3b` at temperature zero. It recorded 179 valid
structured responses and one fail-closed timeout. The raw condition accepted all 90 positive-control
replications and produced 20 permission-level false promotions across 90 negative attempts. Those
promotions came from four negative case designs repeated five times each.

The final cumulative compatibility condition accepted 18/18 positive fixtures, rejected 18/18
negative fixtures, matched 15/15 near misses, and detected 20/20 expected negative failure labels.
This is conformance to purposive fixtures co-developed with deterministic validators. It is not
blinded external validation, a real-world safety guarantee, or evidence that each cumulative layer
has an isolated causal effect.

## Important interpretation details

- Primary raw metrics retain the timeout as a fail-closed system decision. Excluding it changes raw
  reject recall from 70/90 (77.8%) to 69/89 (77.5%).
- Raw safe-reuse accuracy was 63.9% and safe-action accuracy was 75.0%, despite 100% positive-control
  acceptance. Acceptance is therefore not interchangeable with downstream permission.
- Successful repetitions were exactly identical within every case in this temperature-zero run.
  This does not establish stability across model tags, prompts, runtimes, or hardware.
- The model tag is recorded, but an immutable model-weight digest is not.
- Rationale text is retained but not human-coded or included in primary metrics.
